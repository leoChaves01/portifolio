# Portfólio — Leonardo Chaves

Portfólio pessoal desenvolvido em Next.js + TypeScript.

## Rodar localmente

```bash
npm install
npm run dev
```

Depois abra:

http://localhost:3000

## Build

```bash
npm run build
npm start
```

## Estrutura principal

- `app/page.tsx` — conteúdo do portfólio
- `app/globals.css` — todo o visual
- `app/layout.tsx` — metadata e layout base

## Personalização

Os projetos ficam no array `projects` dentro de `app/page.tsx`.

Você pode alterar:
- links dos projetos
- descrições
- tecnologias
- e-mail de contato
- textos da apresentação
